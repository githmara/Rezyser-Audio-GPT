# Режиссер Audio GPT

**Гибридная студия звукозаписи для радиопостановок, аудиокниг и интерактивных историй**

**Другие языковые версии / Other languages:** [English](readme.md) · [Deutsch](readme.de.md) · [Español](readme.es.md) · [Suomi](readme.fi.md) · [Français](readme.fr.md) · [Íslenska](readme.is.md) · [Italiano](readme.it.md) · [Polski](readme.pl.md) · [Русский](readme.ru.md)


Набор автономных инструментов на базе ИИ для автоматического написания, планирования, форматирования и перевода объемных сценариев, а также проведения интерактивных текстовых игр. Проект является нативным настольным приложением (wxPython), разработанным с нуля с учетом полной доступности для экранных чтецов (NVDA, VoiceOver) и совместимости с профессиональными синтезаторами речи (TTS). Работает без браузера и без локального сервера — запускается как обычное окно программы.

Версия: **17.0** · Поддерживаемые языки нативно (9): Polski, Deutsch, English, Español, Suomi, Français, Íslenska, Italiano, Русский.


## Главные модули

Приложение объединяет в одном окне пять инструментов, переключаемых с помощью горячих клавиш (Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 / Ctrl+5) или кнопками на панели инструментов. Каждый модуль работает независимо, но все они используют общие пакеты словарей из папки `dictionaries/` (акценты, шифры, творческие режимы AI) и центральные настройки.


### 1. Режиссура (Ctrl+1)

Главная студия для написания радиопостановок и аудиокниг. Выбираете режим — Мозговой Штурм, Сценарий (с тегами `[SFX]`/`[Персонаж: эмоция]`), Аудиокнига (традиционная проза) — и управляете диалогом с моделью через поле Инструкции + Книгу Мира + Долговременную Память:

* **Многопроектная Книга Мира:** Система автоматически загружает в фоновом режиме посвященные правила вселенной (`.md`) на основе активного исходного файла, обеспечивая полную изоляцию (zero-click context loading).
* **Аккумулятор Сюжета:** Алгоритм «бесконечной памяти». Когда индикатор памяти входит в состояние красной тревоги, система автоматически генерирует краткое содержание сюжета и сохраняет его в поле Долговременной Памяти.
* **4 творческих режимов:** Каждый из файлов в `dictionaries/<jzk>/rezyser/` описывает отдельную «личность» режиссера AI (Мозговой Штурм, Сценарий, Аудиокнига, Постпродакшн Заголовков). Вы можете настроить их звучание без программирования — см. Менеджер Правил ниже.


### 2. Истории (Ctrl+2, второй основной режим с версии 15.0)

Интерактивные текстовые игры, проводимые ИИ в роли повествовательного движка. В отличие от Режиссуры (где вы создаете готовую аудиокнигу), Истории — это пошаговая динамическая сюжетная линия:

* **Режим Выборов:** каждый ход заканчивается 3-5 пронумерованными вариантами A-E. Наиболее интуитивный режим для незрячих игроков — NVDA читает варианты, вы нажимаете Tab и Enter.
* **Режим Меньшего Зла:** как Выборы, но каждый вариант неблагоприятен морально, физически или стратегически. С версии 15.2 дополнительный «флакон» — повторно используемый вариант с нулевой нумерацией для отчаянного спасения, эффекты которого псевдослучайны (60% вредные / 30% искажающие восприятие / 10% редко-полезные, распределение принудительно задается Python, LLM не может придумать спасительный результат).
* **Свободный режим:** любое действие свободным текстом («попробую открыть дверь»), движок предлагает 1-3 предложения, но не навязывает выбор.
* **Модель ИИ для каждого режима:** Выборы и Меньшее Зло используют gpt-4o (лучшее моральное рассуждение), Свободный использует gpt-4o-mini (более экономичная импровизация).


### 3. Полиглот (Ctrl+3, Переводчик AI + Акценты TTS)

* **Безопасный Переводчик:** Длинные тексты автоматически разбиваются на блоки до 10 000 символов и переводятся последовательно. Каждый блок немедленно сохраняется в скрытый файл `.jsonl`. Возобновление после исчерпания лимитов API полностью автоматическое.
* **Автоматизация NVDA:** Переводы сохраняются как готовые файлы `.html` с встроенным языковым тегом или файлы `.docx` с тегами, внедренными непосредственно в структуру XML.
* **8 локальных акцентов:** Возможность намеренного принуждения к ломаному акценту для локальных синтезаторов (Tiflotecnia Voices, eSpeak, OneCore) благодаря продвинутым правилам regex. Поддерживаемые иностранные акценты: английский, польский (с транслитерацией на кириллицу), французский, немецкий, испанский, итальянский, финский, исландский.
* **Режим Шифровальщика:** 6 локальных алгоритмов искажения текста — от чтения задом наперед, через типогликемию, до классического шифра Цезаря. Каждый с локальным алфавитом языкового пакета (например, шифр Цезаря на 35-символьном алфавите PL с диакритическими знаками).
* **Исправитель Тегов:** Безинвазивно внедряет указанный двухбуквенный код языка ISO в существующие файлы.


### 4. Конвертер / Архитектор Аудиокниг (Ctrl+4)

* Обрабатывает исходные файлы `.txt` или `.docx` для клавиатурной навигации в NVDA и системах, таких как ElevenLabs.
* Автоматически преобразует ключевые слова (Акт, Глава, Пролог) в заголовки «Heading 1» в документе Word, а также очищает ненужные HTML-теги и Markdown-разметку.
* С версии 15.1 группировка 5 туров в сцены с заголовками H1 (авто-детекция Историй) — подготавливает файл, сгенерированный в режиме Историй, для традиционной публикации аудиокниг.


### 5. Менеджер Правил (Ctrl+5, новинка с v13.0)

* **Обозреватель словарей без Python:** Визуальное дерево всех файлов YAML в папке `dictionaries/` — фонетические акценты, шифры, творческие режимы Режиссера и Историй. Лингвист или переводчик может просматривать, дублировать, редактировать и удалять правила прямо из GUI.
* **Создатель новых правил:** Форма с выбором типа (акцент, шифр чистых замен, режим Режиссера, новый базовый язык, алгоритмический шифр) создает готовый шаблон YAML, а для более сложных случаев генерирует форматированный запрос для вставки в ChatGPT / Claude.
* **Рефактор v13.0 — правила в YAML:** Все акценты, шифры и режимы AI, которые до версии 12.0 существовали как «вшитые» константы в коде Python, были перенесены в декларативные файлы `.yaml`, загружаемые динамически при запуске приложения. Каждый, кто умеет работать с Блокнотом, может настроить акцент (например, заменить `sz → sh` на `sz → sch`), добавить новый язык, а также изменить звучание системного запроса для AI — без компиляции кода.


## Многоязычность (9 языков нативно)

Начиная с версии 14.0, приложение поддерживает нативно 9 базовых языков: Polski, Deutsch, English, Español, Suomi, Français, Íslenska, Italiano, Русский. Каждая папка `dictionaries/<kod>/` содержит диакритические знаки, алфавит и фонетические правила, которые работают с текстом на этом конкретном языке — приложение автоматически определяет язык источника с помощью lingua-language-detector (по абзацу) и загружает соответствующий пакет для каждого фрагмента отдельно.

Весь интерфейс GUI, документация (`docs/manual.<iso>.txt`) и большинство системных сообщений доступны нативно на каждом из поддерживаемых языков. Системные подсказки AI в режимах Режиссера и Истории написаны на целевых языках (вручную, не автопереведены — см. `dictionaries/<kod>/rezyser/` и `dictionaries/<kod>/opowiesci/`).


## Архитектура AI и используемые модели

Приложение интеллектуально распределяет задачи, оптимизируя затраты и скорость работы API OpenAI:

* **gpt-4o:** Основной движок, приводящий в действие приложение. Отвечает за сложные генеративные задачи: режиссирование сценариев, написание традиционной прозы (Аудиокнига), режимы Выборов и Меньшего Зла в Историях, создание резюме и продвинутые переводы с сохранением многоблочного контекста.
* **gpt-4o-mini:** Быстрая, легкая вспомогательная модель. Используется в фоновом режиме для микрозадач, требующих высокой скорости: итеративное присвоение литературных названий сгенерированным главам, извлечение кодов ISO, Свободный режим в Историях (более экономичная импровизация свободного текста).


### Известные ограничения моделей (Anti-Closure)

Несмотря на внедрение строгих системных директив, предписывающих прерывание действий в моменты напряжения (так называемая директива Anti-Closure), современные модели LLM обладают сильной, врожденной склонностью к "закрытию" историй. Это приводит к частому включению нежелательных выводов, моралей или ложных "счастливых концовок", особенно в Режиме Традиционной Аудиокниги.

Это фундаментальное ограничение текущего поколения искусственного интеллекта. По этой причине приложение сохраняет проекты в обычных, легко редактируемых текстовых файлах (`.txt`). Это требует от пользователя принятия на себя роли живого монтажера — периодического, ручного удаления последних, "закрывающих" предложений, сгенерированных ИИ, с последующей синхронизацией памяти с исправленным файлом кнопкой «Обновить с диска» и продолжением работы.


## Установка и запуск

### Для конечных пользователей (Windows)

1. Загрузите последнюю версию с вкладки **Releases** (пакет, отмеченный как *Latest*) — файл `Rezyser_Audio_v<номер>_Installer.exe`. Запустите его двойным щелчком. Установщик по умолчанию устанавливается в локальный каталог вашей учетной записи (`%LocalAppData%\Programs\Reżyser Audio GPT`) и не требует прав администратора; вы можете выбрать собственный путь с помощью кнопки „Обзор". По завершении создает ярлыки в меню Пуск и на рабочем столе, а также опционально открывает руководство пользователя в стандартном редакторе файлов `.txt`.
2. **Настройка API OpenAI:** При первом запуске приложение сообщит об отсутствии ключа в разделе System Check. Нажмите видимую кнопку, чтобы сгенерировать файл `golden_key.env`, откройте его в текстовом редакторе и вставьте свой ключ (начинающийся с `sk-proj-`).
3. **Первые шаги:** Откройте файл `docs/manual.pl.txt` (или на другом языке) в папке установки — это полное руководство пользователя, написанное доступным языком для каждого пользователя, не только для разработчиков.


### Для разработчиков (клонирование + настройка)

1. Клонируйте репозиторий на свой диск.
2. Запустите файл `setup_dev.bat`, чтобы автоматически создать виртуальную среду (`.venv/`) и загрузить зависимости из `requirements.txt`.
3. Запустите приложение командой `python main.py` или через файл `run_dev.bat`.

Скрипты `.sh` для macOS/Linux были удалены в v13.1 — среда разработки сосредоточена на Windows из-за специфики тестирования доступности NVDA. Работа с кодом на других системах возможна, но требует ручной настройки: `python -m venv .venv && .venv/bin/pip install -r requirements.txt`.

**Скрипты сборки релизных пакетов** (`build_release.py`, `rezyser_audio.spec`, `installer.iss`) предназначены исключительно для создания пакетов для Windows. Начиная с версии 17.0 `build_release.py` замораживает приложение с помощью PyInstaller (onedir + windowed) согласно `rezyser_audio.spec` — создает `dist/` с нативным `.exe` и папкой бандла `runtime/` (интерпретатор + библиотеки). Больше не требуется никакой переносимый Python, загруженный вручную в репозиторий; каталоги `dist/` и `build/` находятся в `.gitignore`.


## Полная документация

Этот README — лишь архитектурный обзор проекта. Чтобы узнать о передовых техниках предотвращения галлюцинаций ИИ, инструкциях по установке совместимых синтезаторов речи (Tiflotecnia Voices, OneCore, eSpeak, Apple Voices), полном описании режимов Истории с флаконом и полном руководстве пользователя, ознакомьтесь с файлами в папке `docs/`:

* `docs/manual.<iso>.txt` — основное руководство пользователя (написано для конечного пользователя).
* `docs/tales.<iso>.txt` — руководство по режиму Истории (интерактивные текстовые игры).
* `docs/dictionaries.<iso>.txt` — инструкция для лингвистов без Python, как добавлять собственные akcenty/szyfry/режимы ИИ.

Каждый из этих файлов доступен на 9 языках — суффикс `.<iso>.txt` (например, `manual.pl.txt`, `manual.en.txt`, `manual.de.txt`).


### Польская терминология — руководство для пользователей, не говорящих на польском

Основным языком этого проекта является польский. Названия модулей, классов, комментарии в коде, а также названия каталогов и файлов данных на польском языке и — для обеспечения обратной совместимости и контракта многоязыкового движка — намеренно НЕ переводятся и не изменяются. Следующий глоссарий поможет разработчикам и пользователям систем macOS/Linux ориентироваться в структуре.

**Каталоги пользовательских данных (рядом с исполняемым файлом или в каталоге проекта):**

* `skrypty/` — *scripts*: проекты модуля Режиссер (`.txt` с повествованием, `.md` с Книгой Мира, `_streszczenie.txt`).
* `opowiesci/` — *stories*: записи интерактивных Историй.
* `runtime/` — двойная роль: каталог бандла замороженного приложения (интерпретатор + библиотеки) И контейнер скрытых метаданных проектов (`runtime/skrypty/`, `runtime/opowiesci/`).

**Подкаталоги исходных данных в `dictionaries/<kod>/` (видимые в Менеджере Правил):**

* `podstawy.yaml` — *basics*: конфигурация и метаданные языкового пакета.
* `akcenty/` — *accents*: фонетические правила для синтезаторов речи.
* `szyfry/` — *ciphers*: режимы шифрования текста.
* `rezyser/` — *director*: творческие режимы модуля Режиссер.
* `opowiesci/` — *stories*: режимы интерактивных Историй.
* `gui/` — тексты интерфейса (`ui.yaml`) и шаблоны документации.
