# Pull Request Comments — historia dyskusji

*Plik towarzyszący `RELEASE_NOTES.md`. Każdy PR zamknięty merge-em do `main` zostaje tutaj udokumentowany własną sekcją: **najnowszy PR na górze pliku** (chronologia odwrócona — czytelnik bez scrollowania widzi ostatnie dyskusje). Komentarze są przepisywane ręcznie przez maintainera ze strony github.com; agent nie wyciąga ich przez `gh api`.*

*Format sekcji per PR:*
- *nagłówek `## PR #N — <tytuł> (merge SHA <skrót>, data <YYYY-MM-DD>)`*
- *podsumowanie 1–2 zdania o czym był PR*
- *lista komentarzy w formacie `> @login: cytat` + krótka notatka decyzyjna pod każdym, jeśli komentarz wymagał akcji w kolejnym cyklu*
- *opcjonalna sekcja „Follow-up" jeśli PR otworzył nowe TODO do następnego release-u*
